Parâmetros Monitorados e Limites

Cada variável coletada é validada contra valores negativos ou nulos (validar_leitura) e comparada aos limiares configurados no dicionário LIMITES.

Parâmetro Chave no Sistema Faixa / Limite Operacional Alerta Disparado Impacto Técnico
Temperatura temperatura_max ≤ 80.0 °C Superaquecimento Degradação do isolamento dos enrolamentos e falha térmica.
Corrente Elétrica corrente_max ≤ 18.5 A Sobrecorrente Sobrecarga mecânica no eixo ou queda de tensão na rede.
Vibração Mecânica vibracao_max ≤ 4.5 mm/s Vibração elevada Desalinhamento de eixo, folga estrutural ou desgaste de rolamentos.
Rotação (RPM) rpm_min / rpm_max 1400 – 1800 RPM Rotação fora da faixa Escorregamento excessivo ou falha no inversor de frequência.
Potência Nominal potencia_kw Monitoramento (kW) Cálculo de carga total Consolida o consumo energético total da planta em kW.
DIAGNÓSTICO AUTOMATIZADO

Lógica de Classificação e Plano Preventivo

A função analisar_alertas() contabiliza quantos parâmetros violaram os limites simultaneamente para definir a severidade e a ação da equipe de manutenção.

0 PARÂMETROS FORA DO LIMITE

1. Operação Estável (NORMAL)

Todas as grandezas estão dentro da zona segura de trabalho. O equipamento segue operando normalmente sem necessidade de intervenção.

1 PARÂMETRO FORA DO LIMITE

2. Inspeção Programada (ATENÇÃO)

Um indicador apresentou desvio isolado. O motor é incluído na agenda de verificação preventiva antes que o desgaste comprometa outros componentes.

2 OU MAIS PARÂMETROS FORA DO LIMITE

3. Parada Imediata (CRÍTICO)

Múltiplas anomalias simultâneas indicam risco iminente de quebra. O sistema recomenda desligamento imediato para evitar danos severos e paradas não planejadas.

IMPLEMENTAÇÃO TÉCNICA

Arquitetura e Código-Fonte Python

Desenvolvido utilizando apenas a biblioteca padrão do Python (datetime), garantindo portabilidade, execução leve e fácil integração com CLPs, brokers MQTT ou bancos de dados industriais.

validar_leitura()

Verifica integridade dos campos obrigatórios e descarta valores nulos ou negativos provenientes de falhas de sensor.

analisar_alertas()

Compara temperatura, corrente, vibração e RPM com LIMITES, retornando o status e a lista de ocorrências.

calcular_estatisticas()

Consolida médias de temperatura e corrente, potência total instalada (kW) e identifica o motor mais quente.

gerar_plano_manutencao()

Agrupa os motores por criticidade (CRITICO, ATENCAO, NORMAL) para orientar a equipe técnica.

monitor_motores.py 
from datetime import datetime

SISTEMA_NOME = "Monitoramento de Motores Industriais"
VERSAO = "1.0.0"

LIMITES = {
    "temperatura_max": 80.0,
    "corrente_max": 18.5,
    "vibracao_max": 4.5,
    "rpm_min": 1400,
    "rpm_max": 1800,
}

LEITURAS_MOTORES = [
    {"id": "MTR-01", "setor": "Estamparia", "temperatura": 68.4, "corrente": 14.2, "vibracao": 2.1, "rpm": 1750, "potencia_kw": 7.5},
    {"id": "MTR-02", "setor": "Usinagem", "temperatura": 84.7, "corrente": 19.3, "vibracao": 5.2, "rpm": 1690, "potencia_kw": 11.0},
    {"id": "MTR-03", "setor": "Bobinagem", "temperatura": 76.2, "corrente": 17.8, "vibracao": 4.7, "rpm": 1520, "potencia_kw": 5.5},
    {"id": "MTR-04", "setor": "Pintura", "temperatura": 61.0, "corrente": 11.5, "vibracao": 1.8, "rpm": 1780, "potencia_kw": 7.5},
]


def validar_leitura(motor):
    campos_obrigatorios = ["id", "setor", "temperatura", "corrente", "vibracao", "rpm", "potencia_kw"]
    for campo in campos_obrigatorios:
        if campo not in motor or motor[campo] is None:
            return False
    if motor["temperatura"] < 0 or motor["corrente"] < 0 or motor["vibracao"] < 0 or motor["rpm"] < 0:
        return False
    return True


def obter_leituras_validas(lista_motores):
    return [m for m in lista_motores if validar_leitura(m)]


def analisar_alertas(motor):
    alertas = []
    if motor["temperatura"] > LIMITES["temperatura_max"]:
        alertas.append(f"Superaquecimento ({motor['temperatura']:.1f} C)")
    if motor["corrente"] > LIMITES["corrente_max"]:
        alertas.append(f"Sobrecorrente ({motor['corrente']:.1f} A)")
    if motor["vibracao"] > LIMITES["vibracao_max"]:
        alertas.append(f"Vibracao elevada ({motor['vibracao']:.1f} mm/s)")
    if motor["rpm"] < LIMITES["rpm_min"] or motor["rpm"] > LIMITES["rpm_max"]:
        alertas.append(f"Rotacao fora da faixa ({motor['rpm']} RPM)")

    if len(alertas) == 0:
        status = "NORMAL"
    elif len(alertas) == 1:
        status = "ATENCAO"
    else:
        status = "CRITICO"

    return status, alertas


def calcular_estatisticas(motores):
    total = len(motores)
    if total == 0:
        return {}

    temp_media = sum(m["temperatura"] for m in motores) / total
    corrente_media = sum(m["corrente"] for m in motores) / total
    potencia_total = sum(m["potencia_kw"] for m in motores)
    maior_temp = max(motores, key=lambda m: m["temperatura"])

    return {
        "total_motores": total,
        "temperatura_media": round(temp_media, 2),
        "corrente_media": round(corrente_media, 2),
        "potencia_total_kw": round(potencia_total, 2),
        "motor_mais_quente": maior_temp["id"],
    }


def exibir_painel(motores):
    print("=" * 64)
    print(f"{SISTEMA_NOME} - v{VERSAO}")
    print(f"Data/Hora da leitura: {datetime.now().strftime('%d/%m/%Y %H:%M:%S')}")
    print("=" * 64)

    for motor in motores:
        status, alertas = analisar_alertas(motor)
        print(
            f"[{status:<7}] {motor['id']} ({motor['setor']}) | "
            f"Temp: {motor['temperatura']} C | Corr: {motor['corrente']} A | "
            f"Vib: {motor['vibracao']} mm/s | RPM: {motor['rpm']}"
        )
        for alerta in alertas:
            print(f"  -> Alerta: {alerta}")

    stats = calcular_estatisticas(motores)
    print("-" * 64)
    print(
        f"Resumo: {stats['total_motores']} motores | "
        f"Temp. media: {stats['temperatura_media']} C | "
        f"Corr. media: {stats['corrente_media']} A | "
        f"Potencia total: {stats['potencia_total_kw']} kW | "
        f"Maior temp.: {stats['motor_mais_quente']}"
    )
    print("=" * 64)


def gerar_plano_manutencao(motores):
    plano = {"CRITICO": [], "ATENCAO": [], "NORMAL": []}
    for motor in motores:
        status, alertas = analisar_alertas(motor)
        plano[status].append({"id": motor["id"], "setor": motor["setor"], "ocorrencias": len(alertas)})
    return plano


def exibir_manutencao(motores):
    plano = gerar_plano_manutencao(motores)
    print("\nPLANO DE MANUTENCAO PREVENTIVA:")
    print(f" - Parada imediata (CRITICO): {[m['id'] for m in plano['CRITICO']]}")
    print(f" - Inspecao programada (ATENCAO): {[m['id'] for m in plano['ATENCAO']]}")
    print(f" - Operacao estavel (NORMAL): {[m['id'] for m in plano['NORMAL']]}")


if __name__ == "__main__":
    motores_validos = obter_leituras_validas(LEITURAS_MOTORES)
    exibir_painel(motores_validos)
    exibir_manutencao(motores_validos)
